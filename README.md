# Claude 会话看板

并发跑多个 Claude Code 会话时，免去逐个切窗口看"跑完没有"——一个常驻窗口告诉你**现在该切到哪个会话去**。

## 安装

解压后直接双击 `ClaudeBoard.exe`（macOS 是 `ClaudeBoard.app`）。

**没有独立的安装步骤**——程序启动时自检，缺什么补什么：

- hook 没注册 → 弹一次确认框，说明要改 `settings.json` 的哪些内容、备份在哪、怎么卸载；同意才写，拒绝就以降级模式运行（少「等你多久 / 本轮用时 / 你敲的原话」三项）
- 桌面快捷方式缺失 → 直接补上（只是多一个文件，无副作用，不打扰）
- 已经装齐 → 静默启动，不弹任何东西

**hook 只对新开的会话生效**，已经开着的会话不会追溯。

卸载：`node install-hooks.js --remove`（只摘本看板的 hook，不动其他来源的配置）。

## 依赖

| 依赖 | 用途 | 缺了会怎样 |
|---|---|---|
| node | 跑 `hook.js` 写状态 | 看板一直是空的（**唯一的硬依赖**） |
| `~/.claude/sessions/` | 精确判定死活/忙闲 | **可选**。没有则自动降级为 hook 推导，不再判定「已关闭」 |

## 使用

日常只做一件事：**扫一眼状态列，看谁在等你**。排序默认按"有多需要你"排，最上面那条就是该先处理的。

- 想要位置固定不跳动 → 顶部「排序」切到**启动顺序**
- 隔夜没处理的会自动降级为「久候」藏起来，勾「显示全部」才出来
- 会话跑完 / 开始等你时会响铃 + 任务栏闪 + 托盘气泡，三个开关都在顶部
- 选中某行，底部显示该会话**最近一轮对话**（你说的最后一句 + 它回的最后一句）

## 状态含义

| 状态 | 含义 |
|---|---|
| ？在问你 | 卡在 `AskUserQuestion` 等你作答，**不理它就永远不会继续** |
| ▲ 等你输入 | 空闲等待你的输入 |
| ✔ 已完成 | 这一轮跑完了，球在你手上 |
| ● 运行中 | 正在干活，不用管 |
| ○ 空闲 | 会话开着但还没交互过 |
| … 失联？ | 心跳静默超过 5 分钟（仅注册表降级时出现） |
| · 久候 | 超过 2 小时没被处理，默认不显示 |
| ✕ 已关闭 | 进程已退出（按 pid 精确判定），默认不显示 |
| · 已隐藏 | 你手动隐藏的，默认不显示；它下次有动静会自己回来 |

## 操作

- **双击行** 在资源管理器打开该会话的工作目录
- **右键 / Delete** 隐藏这一条（≠ 关会话，也不删数据）。勾「显示全部」能找回来，在已隐藏的行上再按一次 = 取消隐藏；该会话下次有动静会自己回到列表
- **Esc / 点空白** 取消选择
- **右上角「?」** 完整说明

## 文件构成

| 文件 | 职责 |
|---|---|
| `app/main.js` | 主进程：开窗、定时推数据、托盘、通知、设置持久化 |
| `app/index.html` | 渲染层：表格、右键菜单、键盘操作 |
| `app/preload.js` | 渲染层与主进程之间的唯一通道 |
| `board-core.js` | 数据层：只算"该显示什么"，不碰界面 |
| `hook.js` | 由 Claude Code 的 4 个 hook 事件调起，写 `state/<session_id>.json` |
| `hidden.json` | 你手动隐藏的会话（墓碑），两套 UI 共用 |
| `install-hooks.js` | 幂等注册/卸载 hook（改用户级 `settings.json`，自动备份） |
| `app/first-run.js` | 首次运行自检：把 hook.js 拷到可写目录并注册 |
| `capture.ps1` / `watch-flicker.ps1` / `close-board.ps1` | 调试工具（截窗口 / 抓帧测重绘 / 发 WM_CLOSE 优雅关闭） |

## 数据来源

| 显示项 | 来源 |
|---|---|
| 会话清单 / 死活 / 忙闲 | `~/.claude/sessions/<pid>.json`（Claude Code 的活会话注册表，**未公开实现**） |
| 等你多久 / 本轮用时 / 摘要 / 你敲的原话 | 本看板 hook 写的 `state/*.json` |
| 心跳（静默时长） | 该会话 transcript 文件的修改时间 |
| 会话标题 | transcript 里的 `ai-title` 记录；没有则用你最近敲的那句 |
| 整体耗时 | 注册表的 `startedAt` |
| 哪些被你隐藏了 | `hidden.json`（墓碑，只记意图不删数据） |

**一行为什么会在**由「注册表 ∪ state 文件」的并集决定。注册表不归看板管——所以"隐藏"只能靠**记一条意图**（`hidden.json`），不能靠删掉某个输入：只删 state 文件的话，注册表还在的那一行下一帧就原地重建，等于删不掉。

注册表是未公开实现，Claude Code 升级可能变动——读不到时看板整体降级、并在健康行明示，不会假装数据还准。

## 已知限制

- **强杀 / 直接关终端 / 关机不会触发 `SessionEnd`**，记录会残留（OS 层限制）。看板靠 pid 交叉校验标出「已关闭」，点「隐藏」即可
- **「等你输入」依赖 Notification 事件**，`bypassPermissions` 模式下覆盖不全
- **双击只能打开目录**，切不到那个终端窗口——拿不到终端窗口句柄
- 桌面/VS Code 里给会话改的名字看板读不到，那是终端标签页名，与 Claude 会话无数据关联
